# BitWork

整数をビット単位で確認・変換するWindows用ツールです。8 / 16 / 32bitとSigned / Unsignedに対応し、Decimal・Hexadecimal・ビット表示を同期します。

`BitWork.exe` を起動し、ビット幅と符号の扱いを選んでください。ビットをクリックすると0 / 1が切り替わります。下部のボタンで全ビット反転、1bit左シフト、1bit右シフトができます。

初期サイズはコンテンツ領域360 × 280（100%表示時）です。ウィンドウの端をドラッグして縮小できます。`TopMost`をオンにすると他のウィンドウより手前に表示され、オフで通常表示に戻ります。式のヘルプは上部の `?` から確認できます。

入力欄では数値や式を入力し、Enterで確定します。

- Decimal: `16*2`、`(100+28)/2`、`-1`
- Hexadecimal: `0x80 & 0x01`、`FF ^ 0F`
- 演算子: `+ - * / % & | ^ ~ << >>` と丸括弧。優先順位はC++と同じです。
- Hexadecimal欄の接頭辞なしの数値は16進数です。`10`は十進数の16になります。両欄で `0x`（16進）・`0b`（2進）を使用できます。

数値と各演算結果は選択したビット幅に切り詰めます。Signedは2の補数として解釈し、除算・剰余・右シフトを符号付きで計算します。Unsignedの右シフトは0を埋め、Signedの右シフトは符号を維持します。幅を広げた場合は上位を0で埋めます。

整数のみ対応します。リテラルの上限は `0xFFFFFFFF`、式は255文字まで、入れ子は64段までです。シフト数は選択幅で評価された値が0〜幅−1の範囲である必要があります。小数・変数・関数には対応しません。不正な式はエラーを表示し、現在の値を保持します。

Windows 10 / 11、Direct3D 11環境で動作します。設定や入力値をファイルに保存しません。描画の初期化に失敗する場合は、グラフィックドライバーを確認してください。
