# BitWorks

整数を10進数・16進数・ビット表示で確認・変換するWindows用ツールです。コンパクトなダークテーマの画面と最前面表示で、コーディング中の数値確認に使えます。

## 主な機能

- 8 / 16 / 32bit、符号付き・符号なしに対応
- 8bitごとに間隔を空けたビット表示（32bitは16bitずつの2段表示）
- ビットをクリックして0 / 1を切り替え
- 全ビット反転、1bit左シフト・右シフト
- 数値に加えて、四則演算・ビット演算の式を入力可能
- `TopMost`で最前面表示を切り替え

## 起動と操作

配布ZIPを展開し、`BitWorks.exe`を起動してください。

1. `8 bit`・`16 bit`・`32 bit`からビット幅を選択します。
2. `Signed`をオンにすると符号付き、オフにすると符号なしで扱います。
3. `Dec`（10進数）または`Hex`（16進数）欄に数値や式を入力し、Enterで確定します。
4. ビットをクリックするか、下部の `~ Invert`・`<< Left`・`>> Right`で操作します。

初期サイズは360 × 280、最小サイズは320 × 260です（100%表示時のウィンドウ枠を除く領域）。ウィンドウの端をドラッグしてサイズを変更できます。`TopMost`をオンにすると他のウィンドウより手前に表示され、オフで通常表示に戻ります。式のヘルプは上部の `?` から確認できます。

## 式の入力例

| 入力欄 | 式 | 結果 |
| --- | --- | --- |
| Dec | `16*2` | 32 |
| Dec | `(100+28)/2` | 64 |
| Hex | `0x80 & 0x01` | 0x00 |
| Hex | `FF ^ 0F` | 0xF0 |

対応する演算子は `+ - * / % & | ^ ~ << >>` と丸括弧です。優先順位はC++と同じです。

`Hex`欄の接頭辞なしの数値は16進数です。例えば`10`は十進数の16になります。両欄で `0x`（16進数）・`0b`（2進数）の接頭辞を使えます。シフト数も入力欄の基数に従います。

## 数値の扱いと制限

数値と各演算結果は選択したビット幅に切り詰めます。例えば8bitでは`255+1`は0になります。ビット幅を広げると上位を0で埋めます。

`Signed`では2の補数として解釈し、除算・剰余・右シフトを符号付きで計算します。右シフトは、符号なしでは上位を0で埋め、符号付きでは符号を維持します。

- 整数のみ対応し、除算の小数部分は0に向かって切り捨てます。
- リテラル（式中に直接書く数値）の上限は `0xFFFFFFFF` です。
- 式は255文字まで、括弧・単項演算の入れ子は64段までです。
- シフト数は選択幅で評価された値が0〜幅−1の範囲である必要があります。
- 小数・変数・関数には対応しません。

不正な式やゼロ除算はエラーを表示し、現在の値を保持します。

## 動作環境と保存データ

Windows 10 / 11、Direct3D 11対応環境で動作します。設定・ウィンドウ位置・入力値をファイルに保存しないため、次回起動時には初期状態に戻ります。

描画の初期化に失敗する場合は、グラフィックドライバーを確認してください。起動中に実行ファイルを更新する場合は、BitWorksを終了してから置き換えてください。
